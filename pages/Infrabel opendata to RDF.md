description:: The Infrabel opendataplatform is a classic platform that allows a download of the datasets in different formats such as csv, excel, json. It is also possible to export the dataset in the RDF serialization, turtle. However, this resulted in a very generic use of a nameless ontology. Datasets were not linked. This project added a YARRRML configuration to the platform to make use of existing ontologies in describing the data in the dataset.
