description:: An enterprise like a railway infrastructure manager, typically has a very siloed data/IT landscape. In order to make certain use cases possible, data has to be integrated between silo's. That's not always possible using existing systems and a spaghetti mess begins. And long term approach to data integration is defining a data centric strategy, meaning to create a data layer based on a single enterprise data model. This project set up several key requirements to becoming data centric. Reporting was done on director and enterprise level.
